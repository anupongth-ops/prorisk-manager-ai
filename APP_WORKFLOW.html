ภาพรวมระบบ (System Overview)

ProRisk Manager AI เป็นเว็บแอปพลิเคชันสำหรับบริหารจัดการความเสี่ยงของโครงการ EPC (Engineering, Procurement, Construction) พัฒนาด้วย React + TypeScript บน Firebase โดยมีระบบ AI (Groq Llama-3) ช่วยแนะนำแผนการจัดการความเสี่ยงอัตโนมัติ

🛡️ Admin

เข้าถึงทุกโครงการ, จัดการผู้ใช้, สร้าง/แก้ไข/ลบ Risk ทุกโครงการ

👤 User

เข้าถึงเฉพาะโครงการที่ Admin กำหนดให้ ไม่สามารถจัดการผู้ใช้ได้

3

การสร้างโครงการใหม่ (New Project)

  1. คลิกปุ่ม "📁+ New Project" ที่ Navbar
  2. กรอก Project Number (ห้ามซ้ำกับโครงการที่มีอยู่), Project Name, PM Name, Email
  3. เลือก Industry Type: Power Plants / Petrochemical Plants / Oil & Gas / Data Centres
  4. เลือก Project Modifiers (Weighting Factors ที่เกี่ยวข้อง)
  5. เปิด "Generate Baseline Risks" หากต้องการให้ระบบสร้างความเสี่ยงพื้นฐาน 31 รายการอัตโนมัติ
  6. คลิก "Create Project" — ระบบจะเปิดฟอร์ม Add Risk ให้ทันที
4

การจัดการความเสี่ยง (Risk Management)

4.1 เพิ่มความเสี่ยงใหม่

  1. คลิกปุ่ม "➕ Add Risk"
  2. เลือก Project และ Risk Category (ระบบสร้าง Risk ID อัตโนมัติ เช่น R-001)
  3. กรอก Description (รายละเอียดความเสี่ยง), Possible Effect, Owner
  4. ประเมิน Initial Risk: Impact (1–5) × Likelihood (1–5)
  5. กำหนด Mitigation Strategy และ Action Plan (หรือใช้ 🤖 AI Suggest)
  6. ประเมิน Residual Risk หลังดำเนินแผน
  7. กรอก Status, Deadline, Comment แล้วคลิก "Save Risk"

5

ระบบ AI (Groq AI Suggestion)

เปิดฟอร์ม Add / Edit Risk │ ▼ กรอก: Description + Impact + Likelihood + Possible Effect │ ▼ คลิกปุ่ม "🤖 AI Suggest" │ ▼ ระบบส่งข้อมูลไปยัง Groq API (Llama-3.3-70B) │ ▼ AI ประมวลผลและส่งกลับ JSON: { "strategy": "Mitigate", "action": "1. ดำเนินการ...\n2. ติดตาม..." } │ ▼ ระบบเติม Mitigation Strategy + Action Plan อัตโนมัติ │ ▼ ผู้ใช้ตรวจสอบและแก้ไขเพิ่มเติมได้
⚠️ ต้องการ: ตั้งค่า GROQ_API_KEY ใน .env.local ก่อนใช้งาน AI
โมเดล: llama-3.3-70b-versatile (ใช้ได้ฟรี)

6.1 Risk Matrix Heatmap

Residual Risk Matrix

💡 คลิกที่เซลล์ใด ๆ ในตาราง Heatmap เพื่อกรองดูเฉพาะ Risk ที่อยู่ในระดับนั้น

6.2 Industry Benchmark Comparison

  1. เลือก Project เฉพาะ (ต้องไม่เลือก "All Projects")
  2. คลิกปุ่ม "Benchmark"
  3. ดู Heatmap 2 แผงเปรียบเทียบ: Actual (จริง) vs Baseline (มาตรฐานอุตสาหกรรม)

6.3 Risk Summary Report

  1. คลิก "📄 Summary" ที่ Navbar
  2. ดูรายงานสรุป: สถิติตามระดับความเสี่ยง, Open Risks, Overdue Risks
  3. พิมพ์ หรือ Export เป็น PDF ได้
7

ประวัติการเปลี่ยนแปลง (Risk History)

  1. คลิกไอคอน 📜 (History) ที่แถว Risk ในตาราง
  2. ดู Timeline การเปลี่ยนแปลงทั้งหมด: วันที่/เวลา, ผู้แก้ไข (Email), ฟิลด์ที่เปลี่ยน, ค่าเก่า → ค่าใหม่
✅ ระบบจะบันทึก History อัตโนมัติ ทุกครั้งที่มีการแก้ไข Risk โดยไม่ต้องกดบันทึกแยก
8

การนำเข้าข้อมูล (CSV Import)

  1. คลิก "☁️↑ Import" ที่ Navbar
  2. เลือกไฟล์ CSV จากเครื่อง
  3. ตรวจสอบ Preview ข้อมูลและ Mapping คอลัมน์
  4. คลิก "Import" เพื่อบันทึกลงฐานข้อมูล

รูปแบบ CSV ที่รองรับ

riskId,projectNo,projectName,category,description,owner,impact,likelihood,status R-001,P001,โครงการ A,Engineering,รายละเอียดความเสี่ยง,John,4,3,Open R-002,P001,โครงการ A,Construction,ความเสี่ยงที่ 2,Jane,3,2,In Progress
