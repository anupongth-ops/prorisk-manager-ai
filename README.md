# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1Bood6eAQlQgEtCZlQBdq6PadbrYLPode

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GROQ_API_KEY` in [.env.local](.env.local) to your Groq API key (get it free at https://console.groq.com/)
3. Run the app:
   `npm run dev`
